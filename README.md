## SQL Playground

El portfolio incluye un editor SQL funcional con un motor SQL escrito en JavaScript puro (sin librerías externas).

Dos tablas reales: `publicaciones` (20 posts) y `semanas` (4 semanas), con datos de gestión de redes sociales (@andika.indum, período abril–mayo 2025).

Incluye chips con queries de ejemplo y esquema colapsable. Shortcut: `Ctrl + Enter` para ejecutar.

## Tecnologías

- **HTML5 / CSS3** — sin frameworks, CSS puro con variables y animaciones
- **JavaScript ES6** — DOM dinámico, IntersectionObserver, motor SQL propio
